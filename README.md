# AI Games

两款经典游戏的浏览器版本，支持键盘操作和单文件离线运行。

- [坦克大战](battle-city.html)：保卫基地，支持单人、双人和地图建造。
- [影子传说](shadow-of-kage.html)：跳跃、攀树、挥刀和投掷飞镖。

下载 `battle-city.html` 或 `shadow-of-kage.html`，用浏览器打开即可游玩。仓库里的文件链接用于查看源码，当前未配置在线游戏站点。

游戏素材与第三方组件来源见 [坦克大战素材说明](assets/battle-city/SOURCES.md)和[影子传说素材说明](assets/legend-of-kage/SOURCES.md)。
