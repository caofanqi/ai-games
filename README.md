# AI Games

三款经典游戏的浏览器版本，支持键盘操作和单文件离线运行。点击“在线玩”直接进入游戏。

| 游戏 | 在线玩 | 查看源码 |
| --- | --- | --- |
| 坦克大战 · 保卫基地，单人／双人／地图建造 | [▶ 在线玩](https://caofanqi.github.io/ai-games/battle-city.html) | [HTML](battle-city.html) |
| 影子传说 · 跳跃、攀树、挥刀与飞镖 | [▶ 在线玩](https://caofanqi.github.io/ai-games/shadow-of-kage.html) | [HTML](shadow-of-kage.html) |
| 魂斗罗 · 丛林第一关与 Boss，支持双人 | [▶ 在线玩](https://caofanqi.github.io/ai-games/contra.html) | [HTML](contra.html) |

[打开游戏大厅](https://caofanqi.github.io/ai-games/)。也可以下载对应的 HTML 文件，用浏览器打开，离线游玩。

GitHub 与 Gitee 的“在线玩”使用同一个游戏站点；“查看源码”用于查看各自仓库中的代码。

游戏素材与第三方组件来源见 [坦克大战素材说明](assets/battle-city/SOURCES.md)、[影子传说素材说明](assets/legend-of-kage/SOURCES.md)和[魂斗罗素材说明](contra-assets/SOURCES.md)。
